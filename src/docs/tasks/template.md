## 🚫 Ограничения (Чего делать НЕЛЬЗЯ)
1. **НЕ** использовать `useState` и `useEffect` напрямую в компонентах View.
2. **НЕ** делать прямых вызовов API/fetch внутри компонентов View.
3. **НЕ** закладывать мок-данные внутрь View — всё должно приходить из ViewModel.
